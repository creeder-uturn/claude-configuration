## Docs and prose

- When writing or substantially editing prose in these files, invoke the `humanizer:humanizer` skill before finalizing and apply its guidance. Skip for mechanical edits: fixing a link, a typo, a code block, a table cell, or frontmatter.

- **Not for instruction or config markdown** — `CLAUDE.md`, `AGENTS.md`, files under `.claude/`, `.cursor/`, `.github/`, or similar. Those are directives, not prose.

- This applies to file content only, not prose written directly in a chat response.
